## BoardReadyOps issue #623 — local versus cloud

The [seven issue acceptance criteria](https://github.com/oaslananka/kicad-studio-kit/issues/623) map to merged extension code and [the versioned CLI integration](../../../../docs/board-ready-ops.md) as follows. **Local regression evidence is not independent native UX or external-cloud acceptance.**

| Issue criterion                                      | Present evidence                                                                          | Full acceptance                                                            |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Version/capability discovery                         | Versioned doctor/schema validation before advanced commands                               | Local contract implemented; native complete journey not certified          |
| Stable findings in diagnostics                       | Project-constrained finding IDs and diagnostics, with regression tests                    | Local implementation evidenced; entire real-project UX not certified       |
| Remediation plan                                     | Structured actionable plan and safe presentation without AI                               | Local implementation evidenced; full user flow pending                     |
| Evidence, review and web governance links            | Local evidence verification, dry-run JSON and deliberate generic web dashboard navigation | **PARTIAL:** no verified real review-specific URL, cloud state or approval |
| Fail-closed release gate                             | Readiness blockers, process/JSON verdict parity and verified local evidence bundle gate   | Local regression evidence; governed release handoff pending                |
| Disabled, missing, incompatible and malformed states | Bounded negative-path tests and safe error/retry behavior                                 | Local tests evidenced; complete native UX matrix pending                   |
| Private-data and credential safety                   | Sanitized paths, stdout/error handling and workspace confinement regressions              | Local tests evidenced; not a live-cloud privacy certification              |

Do not mark the seven issue checkboxes collectively accepted merely because local checks pass.

The previous [published-artifact and loopback-only acceptance](https://github.com/oaslananka/kicad-studio-kit/issues/623#issuecomment-6717076391) exercised genuine published CLI JSON with a disposable synthetic project and a localhost receiver. It did **not** create an externally reachable real review, approval, organization-policy signoff, or signed manufacturing handoff. The Studio UI exposes intentional web-governance navigation and a **dry-run-only** preview, not a verified per-review deep link/state. This is the remaining acceptance boundary; keep #623 open. Do not send user design data, issue cloud review requests or manufacture/ship anything without separate purpose-specific authorization.
